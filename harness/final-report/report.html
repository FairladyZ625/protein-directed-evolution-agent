GB1 虚拟蛋白质定向进化智能体 · 实验报告

在 GB1 突变适应度地形上，用 ML 适应度预测器 + 五角色 LLM Agent 做闭环虚拟定向进化，并对四种推荐策略做诚实对比与失败分析。作者 ZeyuLi · 数据/代码可复现，完整实验入哈希链台账。

一句话结论：在 GB1 四位点地形上，随机策略明显最弱；模型贪心与 LLM Agent 都能在同一预算内逼近甚至达到全局最优 8.762（野生型=1.0）。但我们诚实地发现——GB1 本身是一个可解地形：即便只用 77 个单突变体冷启动，模型引导策略仍能在第 2 轮达峰。因此“能否达峰”不是区分点，真正的区分点是样本效率与批次产出质量：此处 Agent 的聚焦组合库在每种设定下都 ≥ 模型贪心（强命中 56–57 vs 43），而知识增强只带来轻微改变。

一、背景与问题定义

蛋白质定向进化通过“设计→构建→测试→学习”(DBTL)循环迭代寻找高适应度序列；真实湿实验成本高，故用已测数据训练适应度预测器作为“虚拟实验评估器”，让智能体在计算机内提出下一轮突变。本项目要求：(1) 处理真实 GB1 突变-fitness 数据；(2) 训练适应度预测模型；(3) 设计模块化的五角色 LLM Agent 提出突变；(4) 引入知识增强并做消融；(5) 做 2–3 轮虚拟进化；(6) 对比随机 / 模型贪心 / LLM Agent / 知识增强 Agent 四种策略并分析成功与失败案例。核心问题：结构化的 Agent 推理 + 领域知识，是否真的比“直接调用预测模型”更好？

二、数据集介绍

采用 GB1（蛋白 G 的 B1 结构域）四位点组合突变库（Wu et al., 2016）。四个可变位点 V39 / D40 / G41 / V54，野生型序列 VDGV（适应度归一化为 1.0）。理论组合 20⁴ = 160,000，实测有真值的 149,361 个；缺失 10,639 个为真实无测量数据（非人为剔除），报告中明确记为已知局限。

全局最优变体为 FWAA（V39F/D40W/G41A/V54A，与 WT 汉明距离 HD=4），适应度 8.762——即四个位点相对 WT 全部突变。

三、适应度预测模型

特征采用两种：one-hot（4 位点 × 20 氨基酸 = 80 维）与 ESM-2（650M 蛋白语言模型，1280 维 mean-pooled 嵌入）。模型采用阶梯：Ridge / 梯度提升(XGBoost 缺失时回退 GradientBoosting) / MLP，各以 5 seed 深度集成给出均值与方差（供 Agent 做 UCB 探索）。指标：Spearman / Pearson / MSE / Top-k 命中率。

我们特别设置两种切分对比泛化能力：随机切分（分布内）与 HD 外推切分（训练仅 HD≤2 的 2,168 个低阶突变，测试 HD≥3 的高阶突变——模拟“用低阶数据预测高阶组合”的真实困难）。

核心发现（预测器）：分布内两种特征相当（Spearman ~0.48–0.49）；但在 HD 外推下，ESM-2 显著优于 one-hot——MLP Spearman 0.493 vs 0.278，Ridge 的 MSE 0.188 vs 0.483。即蛋白语言模型嵌入把“看过低阶、预测高阶”的泛化能力提上来了。这为后续 Agent 在外推设定下仍能工作提供了基础。

四、LLM Agent 设计

采用模块化五角色流水线（Pydantic schema 校验每个角色的输入/输出），LLM 仅注入两个端口，其余为确定性、可审计逻辑：

  • Data Analyst：统计训练池中各位点/替换的观测适应度，产出位点收益画像。
  • Hypothesis Generator（LLM 端口）：基于分析证据提出最值得组合的替换；无 LLM 或调用失败时回退到“按观测均值取每位点 top-8 替换”的确定性生成器。
  • Mutation Designer：把假设枚举为组合库（每位点至多一个替换、排除全 WT、修复同位点冲突），交下游打分。
  • Fitness Evaluator：调预测器给每个候选出 (均值, 方差)。
  • Scientific Critic（LLM 端口 + 知识规则）：按规则校验候选、接受/拒稿并给理由；--no-knowledge 消融时关闭知识门。

每个角色的动作都追加到哈希链事件流（append-only + SHA-256 链 + fsync），可被 verify() 校验、可在前端 demo 回放——这既是可审计性，也是“展示 Agent 推理过程”的数据底座。LLM 端口接自有 OpenAI 兼容模型池（本报告用 claude-sonnet-5），无凭据/超时时自动降级为确定性生成器，因此项目离线也能完整复现；每轮记录该轮用的是 LLM 还是 fallback。

五、知识增强方法

知识增强在两处体现：(1) 突变规则（合法位点 R-GB1-SITES、≤4 突变 R-MAX-MUTATIONS、无终止子）由 Mutation Designer 结构性保证 + Critic 校验；(2) 在采集函数中叠加 BLOSUM62 保守性软先验 与 UCB 探索：知识增强 Agent 的候选打分 = 预测均值 + 0.75·√方差 + 0.3·BLOSUM62 先验（偏好保守替换）。--no-knowledge 消融同时去掉 UCB 与 BLOSUM 先验，退化为“聚焦组合库 + 纯预测均值”。BLOSUM62、氨基酸理化性质、突变规则与知识图谱构成知识库，规则拒稿能力由单测与 demo 演示。

七、失败案例分析

诚实的元发现：GB1 四位点地形本身可解。我们用极稀疏的 77 个单突变体冷启动，greedy 与两个 Agent 仍在第 2 轮达全局峰 8.762。这说明该地形上位效应有限、低阶数据足以外推到四阶峰——因此“达峰”不能作为方法优劣的判据，这是 GB1 的性质，不是作弊：全局峰 FWAA 不在任何冷启动池内、oracle 为真值查表（题目允许的虚拟评估器）。

  • 随机策略的系统性失败：三档下 random 累计最优仅 2.37–5.08，强变体近乎为零——无预测器引导时，16 万空间里靠运气无法系统逼近峰。这是必要的阴性对照，说明 ML 引导不可或缺。
  • 我们自己的一个真 bug（已修）：组合库最初有 LIBRARY_CAP=2000 的字典序截断，会在预测器打分前把真峰所在组合排除出库，导致 hard 设定下 Agent 一度只到 7.23。定位根因（峰的四个替换都在假设里、但组合被截断）后将上限提到覆盖全部组合（≤6561），Agent 随即达峰。这是“失败→定位→修复”的完整链条，也说明结论对实现细节敏感、须以事件流/台账追溯。
  • 知识增强收益有限：knowledge 与 no-knowledge 几乎持平（hard 强变体 57 vs 56）。原因是预测器已捕获主要信号，BLOSUM 保守先验只是轻扰动；在偏好非保守高阶替换的 GB1 上，保守先验甚至可能与增益方向相悖。这是对“知识增强必然更好”的诚实否证。
  • 模型贪心的“开发过度”：easy 设定下 greedy 停在 8.045、错过真峰，因为它对预测器高置信区域过度开发（全收敛到 G41C/V54A），而 Agent 的聚焦组合库跳出该局部、覆盖到真峰组分。

Agent 是否真学到“科学家思维”，还是只是调用预测模型？诚实的回答：在本任务上，Agent 更像一个结构化、可审计的搜索启发式——它把“分析证据→提出假设→设计组合库→打分→按规则批判”固化为可回放的流程，并在每种设定下以更高的批次产出优于纯贪心；但它不是自主的科学推理，其“智能”主要来自预测器与组合库结构，LLM 端口与知识先验是轻量增益而非决定因素。把这一点讲清楚，本身就是对题目的正面回答。

八、改进建议与未来拓展

  • 更难的地形与目标：GB1 四位点偏易；换更长/更强上位的地形（如 GFP、β-lactamase、AAV），或把目标设为“最少湿实验轮数达到 95% 峰值”，才能真正拉开策略差距。
  • 让知识真正发力：把知识从“软先验”升级为“约束假设生成 + 知识图谱驱动的位点/组合优先级”，并在预测器弱（HD 外推）时加大知识权重。
  • 预测器不确定性驱动主动学习：用 ESM-2 + 深度集成方差做更激进的 UCB/Thompson 采样，量化“样本效率”（达到目标所需测量数）。
  • LLM 深度参与：让 LLM 端口不止提假设，还参与失败复盘与下一轮策略调整（真正的 DBTL 闭环推理），并对比不同模型档位。
  • 严谨评估：多 seed 置信区间、逐轮样本效率曲线、与文献 ML-guided DE 基线对齐。
