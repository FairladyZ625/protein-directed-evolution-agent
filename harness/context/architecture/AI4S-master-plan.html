01题目到底在考什么（原文逐条翻译）

比喻 · 育种

定向进化就是给蛋白质「育种」：随机撒种（突变）→ 挑长得最好的（筛 fitness）→ 拿它当亲本再撒种 → 循环几代，得到想要的品种。2018 年诺贝尔化学奖（Frances Arnold）就是干这个的。你要做的，是把「农民育种」升级成「带 AI 参谋的育种站」——AI 参谋（Agent）看每代的收成记录，建议下一代种哪几块地。

题目原文的任务结构（六大块）

任务题目要什么（白话）翻译成你熟悉的语言
① 数据选一个公开蛋白质突变数据集（题目点了 ProteinGym / FLIP / GFP / GB1 / AAV / β-lactamase），整理野生型序列、突变位点、fitness 分数，划分训练/验证/测试，模拟「已完成的实验 vs 未知候选」选个 labelled dataset，做 train/val/test 切分。切分方式有讲究（下文讲 two_vs_rest）
② 适应度模型训一个 baseline 模型预测突变蛋白的 fitness，用 Spearman / Pearson / MSE / Top-k 命中率评估一个回归任务。Spearman（秩相关）是领域主指标——只要求排序对，不要求数值准
③ LLM Agent五个角色：Data Analyst（读数据）→ Hypothesis Generator（提突变假设）→ Mutation Designer（生成候选序列）→ Fitness Evaluator（调模型打分）→ Scientific Critic（检查合理性）。题目明说「不要求复杂框架，prompt + Python 函数调用即可」一条带校验门的流水线。五个角色里只有两个真正需要 LLM，其余是确定性代码
④ 知识增强建一个「突变规则库」（氨基酸理化性质/保守替换/突变数上限/禁止终止密码子/优先组合历史好突变），可以做知识图谱；硬性要求：对比有/无知识增强的推荐差异规则库 = 配置文件 + 校验器函数。A/B 消融实验 = 加一个开关跑两遍
⑤ 虚拟实验以训练数据当第 0 轮实验结果，Agent 提下一轮候选，用「测试集真值或预测模型」当虚拟湿实验评估器，至少迭代 2-3 轮，看 fitness 是否逐轮提升；对比四种方法：随机突变 / 模型直推 / LLM Agent / 知识增强 Agent一个闭环仿真。四策略对比是报告的主图——这是实验设计，不是工程活，你能拿满分
⑥ 结果分析展示每轮 Top-k 推荐、分析位点集中度、成功案例和失败案例都要、讨论「LLM Agent 是真学到了科学家思维，还是只是调用预测模型」考核重点最后一条就是失败分析。最后一问是钓鱼题（见第 5 节红线）

2.1 五个概念，一层套一层

概念是什么类比
蛋白质一条氨基酸链。20 种标准氨基酸用单字母表示（A/C/D/…/V/W/Y），像一门只有 20 个字母的语言；典型蛋白长 100-500 个字符。链会自发折叠成三维结构，结构决定功能一个超长单词，拼法决定这台「机器」能干什么
突变把链上某个位置的字母换掉（如 39 位的 V 换成 I，写作 V39I）。突变可能让蛋白更好、更差、或没变化改单词里的一个字母，机器性能随机涨跌
fitness一个突变体的「功能分数」——结合强度/荧光亮度/酶活性等，可测量。本题所有数据集的核心标签育种里的「收成」
DMS 数据集深度突变扫描：一次实验批量造几万到几十万个突变体，高通量测序估出每个的 fitness。产出就是一张「突变序列 → 实测分数」的表蛋白质版的 labelled dataset，白送的监督学习数据
上位性 epistasis本题灵魂考点。一个突变的效果取决于其他位点是什么：A 单独有益、B 单独有益，A+B 组合反而有害。后果：适应度景观是崎岖的，贪心组合必翻车两种好肥料一起用烧苗；好调料单吃都行，混一起毁一锅

2.2 蛋白质语言模型（PLM）：为什么「外行」能用

PLM 做的事：把氨基酸序列当文本，用 BERT/GPT 架构在海量天然序列（几十亿条）上预训练。核心信念：进化已经在序列里写下了「什么替换能容忍、什么替换致命」的统计规律。

用法一（零样本打分）：不训练任何东西，直接看模型眼里「突变氨基酸 vs 原氨基酸」的概率变化（LLR），这个分数就是 fitness 的代理。

用法二（嵌入 + 监督回归）：把序列编码成向量（embedding），从 DMS 数据学一个小回归器（Ridge/XGBoost/MLP）——这是本项目适应度模型的标准形态，也是 Science 2025 论文 EVOLVEpro 的同款做法。

关键工程事实（2026-09-10 晚修订）：ESM-2 650M 在 M3 Max 128G 本地实时推理（MPS 加速，单条 56aa 序列约 0.03-0.05s，内存占用 <3GB）——Agent 可自由提出任何合法突变组合，本地即时提特征打分，不存在「候选不在预提取表里」的死表风险。核心认知：ESM 把氨基酸字母变成 1280 维向量——字母只是符号，向量距离才蕴含理化性质/空间结构/进化规律；小模型是在 ESM 提炼好的高维物理表征上学一条到 fitness 的超平面。反直觉教学点照写：650M 反超 3B/15B（论文背书）。

2.3 数据集怎么选：GB1（已定，不摇摆）

比喻 · 为什么 GB1 是完美考场

GB1 是一个只有 56 个字母的小蛋白，实验者把 4 个关键位置（39/40/41/54）的字母组合几乎全部实测了一遍（149,361 / 160,000 种组合都有真分数）。这意味着：你的 Agent 无论提出什么 4 位点组合，都能查到真实 fitness——「虚拟湿实验」不需要任何近似，不会落空，不会作弊。其他所有数据集（比如 GFP，20²³⁸ 种可能）测试集只覆盖极小角落，Agent 提的候选大概率查无此「人」，只能用预测模型兜底，闭环里掺了模型误差。GB1 = 一座全部探明矿脉的金矿 + 完整的化验单。

事实数值对项目的意义
序列长度56 个氨基酸ESM-2 嵌入 CPU 秒级/条；无 GPU 风险
变体规模149,361 条实测（4 位点组合完备）虚拟评估器 = 查表，100% 真值
fitness 含义IgG 抗体结合富集度（log 值）对位题目「提高结合能力」
上位性极强（reciprocal sign epistasis，论文主题）天然产出失败案例——题目考核重点
切分协议FLIP two_vs_rest（训练只见 1-2 点突变，测试推 3-4 点组合）这正是真实定向进化的外推场景，科学叙事现成

数据来源（双保险）：GitHub J-SNACKKB/FLIP 的 gb1 目录（CSV 直下）+ microsoft/protein-uq 同源备份。备胎 AAV 仅当下载失败才启用。GB1 论文：Wu et al. 2016 eLife；ProteinGym 内 assay id SPG1_STRSG_Wu_2016。

2.4 指标：什么叫「好」

Spearman ρ（主指标）：预测值和真值的「排名」相关性。DMS 领域用秩相关是因为 fitness 和功能常呈非线性关系——排名对就行，数值不用准。

Top-k 命中率（定向进化真正关心的）：你预测的 top-10 里，有多少真的进入了全库 top-1%。因为做实验只做最好的那几个孔，中段排序无所谓。

合理预期锚点（不吹牛的底气）：GB1 two_vs_rest 切分下，「ESM 嵌入 + 小回归器」的 Spearman 合理区间 0.55-0.75（FLIP 排行榜量级）。领域零样本 SOTA 全库平均才 0.47-0.52，监督 SOTA 0.61——我们的路线离 SOTA 不远，这有 ProteinNPT 论文数字背书。

4.3 核心战报叙事：「基于主动学习的虚拟蛋白质定向进化双向飞轮」（2026-09-10 修订3 确立）

任务2（训模型）和任务5（虚拟实验）不是两个割裂步骤，是一个双向飞轮：

  1. 冷启动：5,000 条历史数据过 ESM 拿特征向量，训初始回归器（配发「数字测力计」）
  2. 假设与初筛：Agent 像资深科学家一样读历史账本，提 50 个突变假说；本地测力计 0.01s 初筛出 Top-10（Top-K 降维提效）
  3. 虚拟实验化验：10 个候选送入 5 万条真值库查真值（模拟湿实验）
  4. 模型进化与知识反哺：10 条新测定的高价值数据回填训练集（5,000→5,010），微调小模型——测力计逐轮进化

立意高度（答辩用）：这套系统不仅输出高活性蛋白，而且在研发全生命周期中为药企沉淀出一个越来越准的专属数字孪生预测资产——这就是「主动学习」加分项的完整答案。

5.2 用 Harness Anything 开发这套东西（完整链路）

HA 平时是你的「项目操作系统」——每个任务有 fact（现状）/ decision（决策）/ task（执行）三条线，agent 干的每件事都记进事件流。这次笔试是 HA 的双重用法：对外，HA 的事件流机制被精简移植进笔试作品本身（第 4.1 节那个内核），成为「可回放」的卖点；对内，用 HA 的任务体系来开发这个项目本身——四天计划落成 task 树，每个 task 的产出、验收、复盘都在台账里，周六 21:00 检查点就是查 task 状态。

3

06叙事红线（写报告前必读）

红线一：绝不吹「Agent 学到了科学家思维」。题目最后一问「Agent 是否真正学到科学家思维，还是只是调用预测模型」是钓鱼题——它在钓过度宣称。正确答法用消融数据说话：预期策略 3 与策略 2 差距小（LLM 增益有限）、策略 4 与策略 3 的差距来自规则库而非推理能力；诚实结论是「当前 Agent 的价值在于把科学家流程结构化，不在于复现科学家直觉」。这个自省本身就是考核重点最后一条要的答案。

红线二：绝不堆 LangChain / LangGraph 名词。题目明说不需要复杂框架；明度面试官明确反感框架味；自研 loop 让每一步可埋点可校验可回放——这既是技术理由也是审美理由。

红线三：外部资源全声明。FLIP/GB1 数据来源、ESM-2 650M（fair-esm 本地推理）、商业 LLM API、开发过程 AI 辅助——报告末尾统一一节声明（题目 3.a 原文要求）。这同时也是向医药行业展示「合规气质」。

红线四：蛋白知识点到为止。报告里的生物学表述（GB1 功能、BLOSUM 含义、上位性）以 FLIP 论文和教材口径为准，不自由发挥。你是架构师不是生物学家，报告的重心永远在系统。
