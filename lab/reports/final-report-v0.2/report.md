## 摘要

蛋白质定向进化面临天文级序列搜索空间与高昂湿实验成本的双重瓶颈。传统“设计-构建-测试-学习（DBTL）”循环高度依赖人类专家的直觉试错，而纯机器学习方法常受困于局部极值与适应度地形的非线性断裂。

本研究设计并实现了一套**面向蛋白质定向进化的科学智能体系统**。系统由“五角色分工架构（Data Analyst、Hypothesis Generator、Mutation Designer、Fitness Evaluator、Scientific Critic）”构成，严格约束大语言模型（LLM）仅在假设生成与科学审查两处受控调用，彻底杜绝无约束套壳调用。针对定向进化崎岖适应度景观，系统构建了生物物理知识库与“入口空间塑形 + 出口硬拦截”的双层门禁流。

在经典的 **GB1 组合突变景观（149,361 变体）**上，该系统以固定每轮 96 个测试预算进行 3 轮主动学习闭环。实验结果表明：知识增强智能体（Knowledge Agent）凭借 UCB 不确定性引导与保守性先验，**在第 1 轮即直击全局最优变体 FWAA（适应度 8.762，相比野生型提升近 9 倍）**，彻底打破了贪心算法在局部极值（8.045）长达 3 轮的死锁，展现出断层式的样本效率。

在更高维的 **AAV 衣壳蛋白（28 氨基酸高变区，38,265 条数据）**上，本研究展开了四版纵深迭代：
1. **v0.1（自由探索踩坑）**：揭示了经典主动学习在生物学上的根本毒性——“模型预测方差与突变阶数正相关，自由探索会主动掉入高突变死蛋白陷阱”，以 5.96 惨败于贪心（7.53）；
2. **v0.2（双层门禁治决策）**：引入 $\text{HD}\le 4$ 与 BLOSUM62 保守性门禁，彻底消除探索惩罚，将活性拉回 7.53 追平贪心；
3. **v0.3（双盲归因）**：严密诊断发现加性模型与 ESM zero-shot 自然度先验均排不动全局真峰（8.416 隐藏于正上位盲区）；
4. **v0.4（上位感知破顶）**：引入成对残基交互（Pairwise/Potts）模型，彻底粉碎 7.53 瓶颈——**确定性 Gated-Greedy 直达全局最高峰 8.416，LLM Agent 同步突破至 7.829**！

最后，本研究对齐 2024–2026 学术前沿最新共识，深度剖析了“精准表征下纯贪心胜过 LLM Agent 的探索税机制”，并提出了直面断层的无上帝视角“双环自演进科学智能体（Dual-Loop Auto-Research）”顶层架构。

## 第 1 章 背景与问题定义

蛋白质是生命活动的核心执行者，通过定向进化工程改造酶催化活性、抗体亲和力、热稳定性或病毒载体靶向性，是合成生物学与生物医药的核心技术。然而，蛋白质由 20 种天然氨基酸组成，即使对于一段仅 4 个位点的可变区域，理论组合空间即达 $20^4 = 160,000$ 种；若扩展至 28 个氨基酸区域，理论空间高达 $20^{28} \approx 2.68 \times 10^{36}$。受制于高通量测序与文库构建的物理成本，湿实验每轮通常仅能测定几十至数百个变体。

当前蛋白质工程面临三大核心瓶颈：
1. **经验试错效率低下**：人类科学家依赖理化性质和直觉设计，搜索范围受限于有限认知。
2. **纯机器学习贪心策略易陷入局部最优**：监督学习模型受限于初始训练集的覆盖偏差，容易在训练集附近的“山脊”反复徘徊（Local Optimum Trap）。
3. **探索与灭活的根本矛盾**：传统主动学习（Active Learning）鼓励探索模型最不确定的未知区域，但蛋白质结构对突变极度敏感，无约束的大跨步探索往往筛选出大量完全失去折叠活性的“非功能死蛋白”。

为此，本研究旨在构建一个**可替代人类部分认知闭环、具备生物物理规律约束、可解释且防篡改的科学智能体系统**，探索在极小实验预算下逼近全局最优适应度的高效路径。

## 第 2 章 数据集介绍与数据管线

本研究严格基于真实的湿实验测定数据构建虚拟湿实验环境（In-silico Oracle），彻底杜绝数据合成造假。

```
[原始湿实验景观] ───► [严格数据校验与契约] ───► [分层三池切分 (Stratified Splits)]
  - GB1 (149,361条)       - 剔除缺失/异常值          - train_pool (5,000, 模拟冷启动)
  - AAV (38,265条)        - SHA-256 唯一指纹         - query_pool (未测候选池)
                          - 固化野生型(WT)基准       - holdout    (严禁泄露的评估池)
```

### 2.1 数据集选择
1. **GB1 蛋白质 G 结构域 B1（Wu et al., 2016, *eLife*）**：
   - 聚焦于抗体结合核心的 4 个位点：V39、D40、G41、V54。
   - 数据集包含 **149,361 个真实测定的变体**，其野生型（VDGV）适应度归一化为 1.0，全景观真实最高适应度为 8.762（变体 FWAA）。
   - *诚实局限性披露*：理论全组合为 $20^4 = 160,000$ 种，实际测定中存在 10,639 种实验物理缺失变体。本系统将候选提名与评估严格约束在此 149,361 测定空间内，既杜绝了 Oracle 发生 KeyError，又保持了对实验不完备性的科学诚实。
2. **AAV 腺相关病毒衣壳蛋白（Bryant et al., 2021, *Nat. Biotechnol.*）**：
   - 覆盖衣壳蛋白 VR-IV 环区连续 28 个氨基酸区域（野生型：`QED...GNR`）。
   - 数据集包含 38,265 条变体，涵盖从单突变到多达 20 阶的高阶突变，具备极强的高维、稀疏与上位性特征。

### 2.2 数据管线与冷启动三池切分
为真实模拟湿实验定向进化的冷启动与探索过程，数据管线采用按突变阶数（Hamming Distance, HD）分层切分：
- **冷启动训练集（Train Pool, 5,000 条）**：限制以低阶突变为主（GB1 涵盖单突变与双突变；AAV 限制 $\text{HD}\le 2$ 共 10,433 条），模拟实验室初始已有的粗筛文库。
- **查询候选池（Query Pool, 50,000 / 27,832 条）**：作为算法与智能体每轮可探索和提名的候选空间。
- **独立保留池（Holdout, 94,361 条）**：用于离线无偏泛化能力评估。

## 第 3 章 适应度预测模型与特征表征评价

为平衡计算开销与预测精度，系统建立了**三级适应度预测器梯队（Predictor Ladder）**，并对经典 One-hot 编码与蛋白质语言模型 ESM-2 进行了系统的泛化性横向评测。

### 3.1 预测器梯队结构
- **L1 线性基线（Ridge Regression）**：用于评估加性突变效应，具备极高训练效率与可解释性。
- **L2 树模型（XGBoost / Gradient Boosting）**：用于捕捉中等阶数的非线性交互。
- **L3 深度网络（MLP Ensemble）**：多层感知机结合 5-seed Bootstrap 集成，模型不仅输出预测均值 $\mu$，同时输出集成方差 $\sigma^2$ 用于不确定性估计。
- **L4 上位感知模型（EpistasisRidgePredictor）**：显式包含 Degree-2 两两交互项（Potts 式），专门捕捉残基对协同效应。

### 3.2 表征与外推性能对比（GB1 实测）

在随机切分与困难的高阶突变外推切分（HD-extrapolation: 训练集 $\text{HD}\le 2$，测试集 $\text{HD}\ge 3$）下，各模型在测试集上的 Spearman 秩相关系数表现如下：

| 表征方式 × 评估切分 | Ridge (L1) | XGBoost (L2) | MLP 集成 (L3) |
|---|---|---|---|
| One-hot × 随机切分 | 0.484 | 0.474 | 0.389 |
| **ESM-2 650M × 随机切分** | **0.493** | 0.377 | **0.491** |
| One-hot × 高阶突变外推 (HD $\ge$ 3) | 0.358 | 0.354 | 0.278 |
| **ESM-2 650M × 高阶突变外推** | **0.404** | 0.352 | **0.493** |

### 3.3 科学发现与局限
1. **ESM-2 跨域泛化优势**：在高阶突变外推切分下，One-hot 编码性能大幅衰减（从 0.484 暴跌至 0.278~0.358），而 ESM-2 结合深度 MLP 模型依然维持在 **0.493** 的高水平，有力证实了蛋白质通用大模型在捕捉进化隐空间几何结构方面的卓越优势。
2. **Zero-shot 的自然度偏置陷阱**：直接使用预训练模型对数似然差（Log-likelihood ratio）作为适应度打分时，发现其对于人工筛选出的高活性极端变体相关性显著恶化（真峰在 ESM zero-shot 排序中为负分）。这表明预训练模型天然具备“偏好自然进化平庸序列、排斥极端反自然变体”的自然度偏置，不能直接替代监督学习下游拟合。

## 第 4 章 LLM 科学智能体设计

为避免大语言模型在生物分子设计中产生“幻觉”以及“套壳调用”的弊端，本研究基于 PydanticAI 实现了**严格结构化、受控解耦的五角色智能体流水线**。

```
              ┌──────────────────────────────────────────────┐
              │           输入：当前已测变体文库              │
              └──────────────────────┬───────────────────────┘
                                     ▼
                     【角色 1：Data Analyst】 (纯代码)
                     - 统计各单点有益突变谱
                     - 计算位点富集度与方差
                                     │
                                     ▼
                 ★ 【角色 2：Hypothesis Generator】 (受控 LLM)
                 - 结合统计特征与检索到的 T5 规则
                 - 产出假设，强制引用规则 ID [RULE-xxx]
                                     │
                                     ▼
                     【角色 3：Mutation Designer】 (纯代码)
                     - 枚举与组合假设突变 (≤4位点)
                     - 严格限定在合法测定空间，预算去重
                                     │
                                     ▼
                     【角色 4：Fitness Evaluator】 (纯代码)
                     - 调用 T3 预测梯队模型
                     - 计算预测均值 μ 与不确定性方差 σ²
                                     │
                                     ▼
                 ★ 【角色 5：Scientific Critic】 (门禁 + 受控 LLM)
                 - 执行生物物理硬规则校验
                 - 拦截激进突变与结构失活变体，放行候选
                                     │
                                     ▼
              ┌──────────────────────────────────────────────┐
              │       输出：Top-k 最终推荐批次 ──► 存入事件流  │
              └──────────────────────────────────────────────┘
```

### 4.1 五角色职责边界
1. **数据分析师（Data Analyst, 0% LLM 纯代码）**：遍历当前已测文库，统计各位置单点平均增益（$\Delta \text{Fitness}$），消除提示词模糊性带来的统计漂移。
2. **假设生成器（Hypothesis Generator, 受控 LLM ①）**：输入统计报告与检索规则，输出严格遵循 Pydantic Schema，**必须强制引用具体的规则编号（例如 `[RULE-CHARGE-CONSERVE]`）**。
3. **突变设计师（Mutation Designer, 0% LLM 纯代码）**：将假设展开为具体候选变体序列，实施突变阶数截断，去除历史已测样本。
4. **适应度评估器（Fitness Evaluator, 0% LLM 纯代码）**：调用预测器梯队计算预测均值 $\mu$ 与模型方差 $\sigma^2$。
5. **科学评审员（Scientific Critic, 规则引擎 + 低温 LLM ②）**：审查候选序列是否符合疏水性平衡与电荷保守性，具备一票否决权（Reject）。

### 4.2 可审计事件流内核（Auditable Event Stream）
所有智能体角色的输入、决策思考、工具调用以及评估结果，均实时通过 `events/store.py` 写入不可篡改的 **Append-only JSONL 事件流**。每一条事件计算链式 SHA-256 哈希指纹并实时 `fsync` 落盘，确保科研决策链路符合 GMP / FDA 21 CFR Part 11 对计算机化系统的合规追溯要求。

## 第 5 章 生物物理知识增强与双层门禁机制

为防止智能体蜕变为黑盒随机数发生器，系统构建了多层次领域知识库与主动门禁流。

### 5.1 结构化知识库（`rules.yaml`）
- **理化性质本体**：定义 20 种天然氨基酸的 Kyte-Doolittle 疏水常数、侧链静电荷、分子体积与芳香性。
- **BLOSUM62 替换矩阵评分**：将突变划分为保守替换（BLOSUM $\ge 1$）、中性替换（0）与激进替换（$<0$）。
- **知识图谱关系**：通过 NetworkX 构建 `(AminoAcid)-[has_property]`、`(Mutation)-[occurs_at]`、`(Variant)-[contains]` 三元组图谱。

### 5.2 双层 Knowledge 门禁流机制
针对自由探索容易落入失活区的特点，系统设计了**双层门禁（Dual-Gate Guardrails）**：

| 门禁层级 | 插入位置 | 实施方式与规则 |
|---|---|---|
| **入口空间塑形门** | `list_pool`（候选检索工具） | **主动塑造候选子空间**：限制仅返回满足突变数 $\text{HD}\le 4$ 且平均 $\text{BLOSUM62}\ge 0$ 的变体，使智能体天然在功能相容区采样。 |
| **出口硬拦截门** | `test`（真值评估前） | **刚性预算保护**：提议序列必须通过电荷中和与体积冲突校验，被拒序列不消耗真实实验预算，并打回让智能体重新假设。 |

## 第 7 章 失败案例深度复盘与机理归因

科学研究的核心价值在于剖析失败。本章基于 AAV 数据集上的实测失败与突破展开深层次机理剖析。

### 7.1 失败案例一：自由主动学习的“死蛋白陷阱”
在 AAV 数据集上，赋予智能体完全自由的工具调用权限（`v0.1 agentic SOL`）时，其最终表现仅为 **5.96**，大幅输给贪心算法（7.53）。

- **机理尸检**：
  - 主动学习经典法则提倡“探索模型方差最大的样本”。
  - 但数据诊断显示：**模型预测方差与突变阶数呈现强正相关（$r = +0.47$），而与真实活性呈强负相关（$r = -0.31$）**。
  - 纯探索模式挑出的候选平均突变数高达 **16.98 个**，真实平均适应度为 **-4.60**（100% 失去功能）。
  - *结论*：在蛋白质适应度景观中，认知不确定性与序列致死率天然绑定。**脱离生物物理刚性门禁的主动学习本质上是“主动筛选死蛋白”。**

### 7.2 失败案例二：加性模型的“上位效应盲区”
真实全景观最高峰为 **8.416**（变体 `D0Q + S17E + V18A`），但在 v0.1~v0.3 中所有策略均无法逾越 7.53。

- **机理尸检**：
  - 真实峰由 3 个位点协同产生（实测 8.416，但单点加性效应总和仅有 6.30），蕴含强烈的**正上位效应（Positive Epistasis, $1+1+1 \gg 3$）**。
  - 加性模型表达力不足，将该变体排在门内第 **2,776 名**（不可达）；ESM-2 大模型因该组合在自然界中罕见而判定为负分。该变体陷入“加性低估 + 自然度排斥”的双盲区。

### 7.3 v0.4 破顶与“探索税（Exploration Tax）”机制深度剖析
在 v0.4 中，系统将预测器换为显式含成对残基交互项的 `EpistasisRidgePredictor`，真峰在候选池中的排名瞬间由 **#2776 飙升至 #429**，直接打破了天花板。

**然而出现了一个极具启发性的现象：确定性 Gated-Greedy 直达全局最高峰 8.416，而聪明的 LLM Agent 止步于 7.829。**

其根本机制在于**“弹药集中度”与“探索税”的博弈**：
1. **表征决定物理上限**：上位感知模型一旦把真峰排入前沿，物理天花板被彻底掀开；
2. **高信噪比下的策略差异**：
   - 确定性 Greedy 策略将 288 次预算 **100% 毫无保留地集中在预测前列**，直接收割真峰 8.416 与 151 个强变体；
   - LLM Agent 拥有“兼顾探索与利用”的自主性，每轮主动分流 20%~30% 预算去探测未知多样性。在极度有限的 288 预算下，这笔**沉重的“探索税（Exploration Tax）”**稀释了强攻第一峰的弹药，使其止步于第二高峰（7.829）。

这证明了学术界的核心共识：**表征的表达力是能否触达全局峰的决定性杠杆，而在优质模型就绪后，下游利用步的无节制自主探索反而会拖累收敛速度。**

## 第 8 章 面向下一代自主科学智能体：从“驯化自主”到受控递归自演进（RSI）的范式跃迁

### 8.1 范式反思：“确定性垫底 + LLM 置顶”的过渡期局限与归纳窒息

在 2024–2026 年的科学智能体（AI for Science）文献中，主流共识普遍呈现向“去自主化”与“驯化自主（Taming Autonomy）”收敛的态势（*Are We There Yet?*, 2509.21403；*ALDE*, Nat Commun 2025）。这类研究指出，在局部参数利用步，大语言模型（LLM）由于统计校准偏差与非受控的多样性采样，其搜索效率显著落后于经典贝叶斯优化、高斯过程或确定性贪心算法；因此主张将确定性数学模型固化为底层执行内核，仅让 LLM 置于外围负责文献解析或自然语言实验协议生成。

在本项研究（v0.1 至 v0.5）的工程实践中，我们同样记录到了这一表象：当高阶上位感知代理模型就绪后，确定性贪心策略仅消耗 288 实验预算即直达全局真峰（8.416），而自主 LLM 智能体因固执地进行不确定性探索而止步于次优区域（7.829），支付了高昂的“探索税”。

**然而，本研究旗帜鲜明地指出：这种“确定性垫底 + LLM 置顶”的双层架构并非科学智能体的终局范式，而仅仅是上一代技术周期的防御性妥协。**  
其核心缺陷在于将底层代理模型与采集策略固化为静态黑盒，从而诱发了**归纳窒息（Inductive Asphyxiation）**：
1. 底层数学优化算法的探索边界严格受制于先验假定（如一阶线性加性假设或二阶 Potts 势能假定）；
2. 当适应度地貌出现未知的高阶协同效应或超出先验分布的剧烈跳跃时，静态底层算法将在错误的局部凸起处彻底锁死，且在数学上无法自发完成表征空间的维度跃迁；
3. 置顶的 LLM 因缺乏对底层算法机理的内省通路与可计算的因果凭证，只能在外围产生泛化的自然语言引导，最终退化为一层包裹在经典算法外表上的“自动化运维脚本”。

要实现从“机械化自动化实验”向“真正自主科学发现”的跨越，智能体必须具备识别自身表征缺陷、内生性提出新假说、并自主重构底层算法与实验工具链的元演进能力。

### 8.2 核心科学假说体系（Four Foundational Hypotheses）

为打破“驯化自主”的技术天花板，我们基于**递归自我改进（Recursive Self-Improvement, RSI）**与**因果证据账本（Fact-Decision-Task Ledger）**的交叉原理，构建了指导下一代科学智能体研发的四项底层理论假说：

```
┌─────────────────────────────────────────────────────────────────────────────────┐
│                      下一代自主科学智能体四大科学假说体系                          │
├───────────────────────────────┬─────────────────────────────────────────────────┤
│ 假说 1: 认知状态与执行解耦假说 │ 搜索前沿(Frontier) ╪ 因果事实图(Fact DAG) ╪ 局部执行上下文(Context) │
│ (Epistemic Decoupling)        │ ⇒ 消除上下文漂移与反馈钝感，探索税趋向于理论极小值               │
├───────────────────────────────┼─────────────────────────────────────────────────┤
│ 假说 2: 结构化账本反事实归因假说 │ 实验轨迹编译为全生命周期不可篡改事件流(Event Stream)             │
│ (Counterfactual Attribution)  │ ⇒ 自主分离“表征表达力缺陷”、“采样病理”与“门禁错位”               │
├───────────────────────────────┼─────────────────────────────────────────────────┤
│ 假说 3: 双环分级系统元演化假说 │ 内环刚性利用 + 外环方法论重构，外部物理验证器(Verifier)硬隔离    │
│ (Staged Dual-Loop RSI)        │ ⇒ 算法与工具代码级受控自变异，数学上免疫 Goodhart 评价作弊       │
├───────────────────────────────┼─────────────────────────────────────────────────┤
│ 假说 4: 信息论价值驱动实验选择假说│ 摒弃盲目多样性，基于 Value-of-Information (VoI) 联合优化增益与成本│
│ (Information-Theoretic VoI)   │ ⇒ 有限湿实验预算下，主动探索的全局收敛效率显著击败纯贪心         │
└───────────────────────────────┴─────────────────────────────────────────────────┘
```

1. **认知状态与执行解耦假说（Epistemic State Decoupling Hypothesis）**：将全局搜索前沿、因果事实图与局部单步执行上下文物理分离，通过条件路由召回，消除长周期决策中的注意力漂移与反馈钝感，将探索税压制在理论下界。
2. **结构化事件账本的反事实归因假说（Counterfactual Credit Assignment Hypothesis）**：依托不可篡改的事件流血缘追踪，自主反事实诊断平台期根本因果——精准分离表征表达力缺陷、采样函数病理与门禁边界错位，避免盲目超参扰动。
3. **分相分级的系统元演化假说（Staged Dual-Loop Self-Evolution Hypothesis）**：内环稳定收割，外环改进器在独立影子沙箱中对模型代码与策略实施变异；以物理守恒定律与外部只读评估器作为最高不变量门禁，数学上免疫评价作弊（Goodhart's Law）。
4. **信息论价值驱动的实验设计假说（Information-Theoretic Value-of-Information Hypothesis）**：基于信息价值函数（VoI）权衡参数不确定性缩减收益与物理实验成本，使主动探索在复杂崎岖地貌上的全局收敛能力显著超越纯贪心算法。

### 8.3 顶层架构设计：基于事实-决策账本的五机双循环科学自演进系统

```
┌─────────────────────────────────────────────────────────────────────────────────┐
│                       外层元科学演化环 (Meta-Scientific Evolutionary Loop)        │
│                                                                                 │
│   ┌────────────────────────┐      因果反事实归因      ┌──────────────────────┐  │
│   │   ④ 记忆器 (Memory)    │ ───────────────────────> │ ⑤ 改进器 (Improver)   │  │
│   │  - 事实图谱 (Fact DAG) │                          │ - 表征模型演进器     │  │
│   │  - 决策账本 (Decisions)│                          │ - 采集函数退火器     │  │
│   │  - 运行审计 (Ledgers)  │                          │ - 物理门禁校准器     │  │
│   └───────────▲────────────┘                          └──────────┬───────────┘  │
│               │ 提取结构化实验因果                               │ 提出代码级候选Patch
└───────────────┼──────────────────────────────────────────────────┼──────────────┘
                │                                                  ▼ (影子沙箱回归校验)
┌───────────────┼──────────────────────────────────────────────────┼──────────────┐
│   ┌───────────┴────────────┐                          ┌──────────┴──────────┐   │
│   │   ③ 控制器 (Controller) │ <=====================>  │ ② 验证器 (Verifier) │   │
│   │   - 实验轮次调度器     │     执行合法性裁决       │ - 生物物理硬门禁     │   │
│   │   - 探索/利用动态配比  │                          │ - 外部客观测试集     │   │
│   └───────────┬────────────┘                          └──────────▲──────────┘   │
│               │ 驱动执行                                         │ 物理拦截与数据回传
│               ▼                                                  │              │
│       ┌───────────────────┐                                      │              │
│       │ ① 执行器 (Executor)│ ─────────────────────────────────────┘              │
│       │ - 高阶模型打分    │        输出测试变体与实验测量读数                     │
│       │ - 确定性批次生成  │                                                      │
│       └───────────────────┘                                                      │
│                               内层实验执行环 (DBTL Operational Loop)              │
└──────────────────────────────────────────────────────────────────────────────────┘
```

1. **内层实验执行环（DBTL Operational Loop）**：由**执行器（Executor）**、**验证器（Verifier）**与**控制器（Controller）**协同。执行器使用当前最优模型生成确定性批次，验证器基于物理法则与留出基准执行最高裁决，确保每一轮实验执行零探索税、不可作弊。
2. **外层元科学演化环（Meta-Scientific Evolutionary Loop）**：
   - **记忆器（Memory）**：依托不可篡改的 **Fact（事实）** 与 **Decision（决策）** 账本，贯彻 *“A failure should pay rent”* 原则，将失活数据转化为负向搜索先验；
   - **改进器（Improver）**：监测内环边际收益衰减，在探测到平台期后自主检索物理文献，在隔离影子沙箱中对代理模型（如加性向成对交互重构）、特征算子与门禁规则生成代码级补丁，验证通过后作为下一代执行内核激活。

### 8.4 演进路线图：从“自动化脚本”向“通用科学发现器”的三阶跃迁

1. **第一阶段：工程化自动化流水线（当前 v0.1 至 v0.5 水平）**：外围提示词注入质量认知，底层采用高阶上位感知模型并引入自适应退火批次（`compose_batch`）。模型选型与超参形式仍依赖人工离线诊断，属于高级自动化执行脚本。
2. **第二阶段：受控自演进可审计科研系统（近期攻关目标）**：全面集成 Fact-Decision-Task 实体账本与事件流。无上帝视角平台期探测器自主发现“上位表达力赤字”，在影子沙箱中自主完成加性向成对模型的代码重构，实现特定靶点内的自发方法跃迁。
3. **第三阶段：通用递归自演进科学发现器（终极愿景与湿实验对接）**：跨靶点提取通用高阶物理规律；主动设计信息论最优的探针实验；直连 OT-2/Tecan 液体处理工作站与高通量测序仪，实现全无人化“假设-实验-表征-演进”的终极物理闭环。
