物理与生物化学底层

许多计算机背景的研究者容易把蛋白质设计简单当成一个连续数值优化问题。然而，生物大分子是一个典型的高维离散、非凸、崎岖且充满断层的“自旋玻璃（Spin Glass）”能量地貌。

1️⃣ 经典加性假设的致命破产

传统的机器学习（如 Ridge 线性回归、简单神经网络）默认采用加性假设（Additive Assumption）：认为每个残基突变的效果是独立累加的：

f_{ ext{additive}}(oldsymbol{x}) = f_0 + \sum_{i=1}^L h_i(x_i)

为什么会死？如果突变位点之间在三维空间中互相接触，它们会形成盐桥、氢键或空间位阻。这就导致：“1 + 1 不等于 2，甚至 1 + 1 = 0（致死）或 1 + 1 = 10（暴击）”。这种残基之间的非线性相互作用，在遗传学与物理学中被称为上位性（Epistasis）。

2️⃣ 统计物理广义 Potts Hamiltonian

真实的蛋白质能量曲面遵循统计力学中的广义 Potts 相互作用模型（白皮书一理论推导）：

H(oldsymbol{x}) = \sum_{i=1}^L h_i(x_i) + \sum_{i < j} J_{ij}(x_i, x_j) + \sum_{i < j < k} K_{ijk}(x_i, x_j, x_k) + \dots

其中 $J_{ij}$ 表示二阶成对相互作用势能，$K_{ijk}$ 表示三阶残基微环境协同。当成对与高阶项符号相反时，能量地貌就会出现阻挫（Frustration）——形成极其崎岖的自旋玻璃地貌，局部极值星罗棋布。

为什么在有限预算下探索会变成“税负”？
• 在无穷步（$T o \infty$）下，探索必不可少；

❓ Q4：你们如何保证实验过程没有“偷看答案（Data Leakage）”？

高分应答：我们的系统在架构级别实现了绝对的隔离与防泄露：
1. 只读 Verifier 物理隔离：真机标签存放在独立的只读环境中，智能体在提出 48 个候选批次之前，完全接触不到任何候选的真实分数；
2. 单向离线回测闭环：在 14 组离线回测中，Oracle 每次只向算法开放当前批次的测定值，严禁提前排序；
3. 不可篡改事件流审计：每一轮所有的输入提示词、LLM 输出、工具调用参数以及测定回执，全部由带有 SHA-256 签名和时间戳的 Append-only JSONL 事件流严格固化，任何人包括开发者都无法在事后修改实验日志。

❓ Q5：如果要把这套系统应用到药企真实的湿实验（自动化工作站）上，你们的架构怎么对接？

高分应答：我们的五机架构天然就是为了物理世界对接而设计的：
• 内环的 Executor（执行器）可以通过标准 SiLA 2 或 RESTful API 对接自动化液体处理工作站（如 Hamilton Microlab STAR 或 Tecan Fluent），将算法生成的 48 个序列直接编译为移液加样脚本（Worklist）；
• 测序仪或荧光酶标仪的读数生成后，由 Verifier（验证器）作为数据守卫，进行标准化清洗与质控校验，直接沉淀进不可篡改的事件账本中；
• 整个闭环在无人值守的情况下持续运转，人类科学家只需在大本营看板（Streamlit / Web Timeline）上实时监控系统自演进的决策血缘。
