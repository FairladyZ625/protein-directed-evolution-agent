# v0.7 建设性结论：让 DE agent 优化实验价值

> 一句话：称职的 DE agent 应在固定预算下最大化事先约定的、经实测确认的强变体期望产量，以利用为主，只在探索的预期增益足以支付机会成本时探索。

本文是决策论建议与 future-work，**没有实现新策略，也没有重跑 campaign**。只用本地材料与任务提供的共享事实；不联网。既有结果仍按原指标报告，不能因为峰命中不理想，事后更换指标宣布获胜。

更关键的是：cold-start 已知最高值 **9.536457 > 池内峰 8.416205**。因此“发现池内峰”不是“超越已知最优”。若研究目标真是获得比所有已知蛋白更好的单一产品，本次有限池事后可知无法完成；在线 agent 却不能偷读全池标签提前作此判断。

本地 frontier synthesis 与任务提供的 Greenman/FLIP-AAV 结论支持“greedy 是强基线”的方向性判断；本文未独立核验外部论文，不把它们当通用定理。FLIP-AAV 原生是稀疏回归基准，本项目在其上构造池式优化任务；样本池最大值没有天然的全局生物学最优地位。

## 2. 先定义效用，再谈探索率

设当前历史为 D_t，只含已测序列及标签；P_t 是合法未测池。策略 π 依赖 D_t、序列特征、surrogate 预测与已测数据内的验证结果。S_B 是预算 B 内新增测得的**不同**变体集合，不能重复计数或把 cold-start 当新发现。

令 τ 是开跑前约定的可用性门槛，定义：

\[
N_\tau(S_B)=\sum_{x\in S_B}\mathbf 1\{f(x)\geq\tau\},\qquad
J_{\rm yield}(\pi)=\mathbb E_\pi[N_\tau(S_B)\mid D_0],\quad
\sum_{x\in S_B}c(x)\leq B.
\]

本项目等成本查表时 c(x)=1；湿实验时必须计入合成失败、复测与回合成本。D_0 的成本在当前比较中视作共同沉没成本，不能把 288 宣称为从零开始的全部研发投入。

“多一个强变体都有价值”是假设，适用于获得可进一步筛选的候选库。若只需要 K 个合格候选，可改为 E[min(N_τ,K)]；若候选高度冗余，应在效用里定义功能类别覆盖或边际价值递减，而不是用序列距离自动冒充功能多样性。拥有大量已有强候选时，也需说明新增候选的实际用途。

在线 τ 应来自应用规格、事先可用的参考数据或固定 cold-start 规则。原 benchmark 的全表 top10% 阈值可以留在**隔离的评估器**中做描述性打分，不能把未测标签算出的分位点透传给 agent 或用来调策略。原 strong 与新定义的应用合格率不能悄悄视为同一指标。

若突破性候选另有价值，用同一效用单位写成：

\[
J(\pi)=\mathbb E_\pi\!\left[vN_\tau(S_B)
+\lambda\{h(M_B)-h(M_0)\}\mid D_0\right],\quad
M_B=\max\bigl(M_0,\max_{x\in S_B}f(x)\bigr).
\]

- v 是一个新增合格变体的价值；λ 是额外突破收益的权重，均由实验目的事先决定。
- M_0 是所有已知测量中的最好值；h 可取连续质量效用，或预先指定目标 T 的达标奖励 h(m)=1{m≥T}。
- “单峰彩票”可另记为 E[1{S_B 含池内最优}]，但其目标身份只能由评估器事后判定；通常不如应用阈值具有科学可解释性。
- 如果只在意一个可交付的最佳产品，v 可以为0；不能把“多产强变体”强加给该需求。反之，λ=0 时不应为了榜单上的单峰牺牲大量产量。

本次 AAV 池内所有候选事后均低于 M_0，因此上述最佳产品改进项全部为0；原 `cum_top10_max` 是仅对新增测量定义的另一个统计量，仍应保留并明确命名。

λ 大时选择回报分布更偏向极端收益的策略可以完全理性；**高方差本身既不是奖励，也不是信息价值**。风险中性的期望效用已足以表达这类偏好。只有实际业务需要最低产量保证时，才另外事先约定如 Pr(N_τ≥K)≥1−δ 的约束，而不随结果增删。

## 3. 利用应该排什么

对当前等成本批次 A，若只计新增合格数，其即时预期效用是：

\[
R_t(A)=v\sum_{x\in A}p_t(x),\qquad
p_t(x)=\Pr(f(x)\geq\tau\mid D_t).
\]

因此单步最优是选最大的 p_t，而不是无条件选最大的预测均值。期望可加不要求候选之间独立；但批次学习收益、至少一个达标的概率和最佳值期望需要处理候选相关性。

若预测分布校准良好，且各候选同为等方差的位置分布，p_t 与均值排序一致；异方差时一般不成立。当前 `(mean,var)` 接口与几个 bootstrap 的方差，不能凭空提供可信的尾部概率：还需要分布假设及校准证据。

所以**目前以纯均值作为利用基线是有本地证据的实用选择，而非“已经实现期望产量最优”**。后续若构建 p_t，须在已测数据内验证阈值附近与头部的可靠性。CV Spearman 高只说明整体排序，不能推出尾部已校准，也不能用 ρ² 直接解释探索收益或设定探索比例。

## 4. 探索何时值得：支付机会成本的判据

用终局效用 U(D) 表示上节目标，令 b 为剩余预算，则原则上的决策是：

\[
V(D,b)=\max_{A\subseteq P_D,\ c(A)\leq b}
\mathbb E_{Y_A\mid D}\left[V(D\cup(A,Y_A),b-c(A))\right],
\qquad V(D,0)=U(D).
\]

其中 A 应满足实际批次及门禁约束；预测只用于计算决策预期，Y_A 必须来自花预算后的独立测量/查表。这个 Bellman 形式是定义，不是声称当前系统能精确求解。

把等成本探索批 E 与利用批 G 比较，写成更直观的条件：

\[
\underbrace{\Delta R_{\rm breakthrough}}_{\text{本批直接突破收益}}
+\underbrace{\Delta C_{\rm remaining}}_{\text{后续净效用差}}
>\underbrace{v\!\left[\sum_{x\in G}p_t(x)-\sum_{x\in E}p_t(x)\right]}_{\text{放弃即时强变体的机会成本}}.
\]

ΔC_remaining 必须比较两批测完后、相同剩余预算下的完整后续决策，包含重拟合、候选消耗与仍可兑现的突破收益。它不是 UCB 的 βσ，也不是熵下降；两批都产生信息，探索要证明的是**相对利用的净增量**。

严格的信息价值是“看见新测量后再优化后续动作”的期望效用，减去“不能看新测量就固定后续动作”的最优期望效用，且两者使用相同剩余候选与预算。可信模型下信息本身可忽略，故此值非负；为获得信息而牺牲多少好候选、花多少成本，另算。实际模型错配时，重训还可能使决策更差，不能套用理论非负性保证实测收益。

探索值得的具体条件包括：

1. 有可学习的认知不确定性，测该点可能改变其他可选候选的决策排序；不能把不可约测量噪声误当可转移信息。
2. 有足够剩余实验名额和反馈回合将排序改善转成收益；只提高模型指标、来不及测新候选，不算本项目终局效用。
3. 后续可达候选足够多、信息不过度冗余；学习出的结论若只适用于门外序列，就不能在当前门内预算里兑现。
4. 或者无需学习，该候选在已约定的 h、λ 下就有更高直接尾部收益；这属于对所选效用的利用，可以发生在最后一批。
5. 收益估计经过已测数据内的隔离验证，且相对机会成本足够稳健；没有可信估计时不伪造 VOI 数字。

示意而非实测：替换8个候选，合格概率从0.75降到0.25，预期损失4个强变体；若因此使后续40个候选的平均合格概率净增0.12，则获益4.8个，净增0.8个，探索值得。若只剩10个后续名额，获益1.2个便不足。此处假定净提升可实现、成本相同且无额外突破奖励。

**最后一批的本次任务信息价值为0，但直接尾部收益未必为0。** 固定“最后两轮纯均值”并非所有目标的定理；固定“最大值两轮不涨就整批探索”也不成立，因为最大值停滞时仍可能持续高产 strong。

## 5. 一个可辩护的 agent 策略建议（本次不实现）

默认任务声明为“预算内新增可用候选库”，以纯均值为当前基线，保留相同池、门禁、预算、oracle 与完整已测标签。待可信的阈值概率可用后，以预期合格收益排序替代均值代理。

每批前让 agent 提交简短决策记录：当前目标与剩余预算、利用批的预期收益、探索拟减少什么误差、预期在哪些后续可行候选上兑现、替换名额的机会成本。LLM 可以提出可检验假设、组织工具和解释异常；最终名额由明确的采集规则分配，不能用一段“该跳出局部最优”的叙述覆盖数值依据。

只有已测数据支持上述净收益条件时才提高探索份额；没有可靠 VOI 估计时，默认继续有证据的利用。若任务另含模型审计或为下一项目积累知识，可事先划定有限诊断预算并说明其独立效用；不能声称存在科学必需的固定10%探索率。探索可用 UCB/多样性作待验证近似，但它们不是效用最优的证明。

触发依据应是目标相关的预期产量衰减、已测批次的预测残差或支持范围不足；最大值停滞只触发诊断。序列距离可作软约束，但除非有应用理由，不增设硬“换构成”门。保留失败标签，切采集函数不等于抹去历史、退还预算或重新开始。

预注册候选策略后，在与部署相近的已测数据隔离切分中比较等预算轨迹；模型/比例选择与最后确认数据分开。随机拆分可能掩盖外推误差，自适应采样历史也有选择偏差，不能把这种内部验证当全池真值。必要的模型改进验证应加 shuffle 标签阴性对照。

以后正式比较主报新增合格数及其预算曲线，辅报新增最佳值、相对已知 incumbent 的改进、Top-k、成本与失败数；报告跨 seed/数据切分分布和未达目标的轨迹。概率策略还要查校准。原 top10% strong 单列为 benchmark 指标。

本次三 seed 矩阵只能支持“先采用利用主导的保守默认”。交替平均少16.3333个 strong、SEMI 少17个，换来各一次池内峰命中；这些是观测到的结果差额，不是可直接代入 λ 的真实成功概率，也不是探索造成损失的独立因果估计。新的确认实验不能沿用已看过峰的测试池来挑赢家。
