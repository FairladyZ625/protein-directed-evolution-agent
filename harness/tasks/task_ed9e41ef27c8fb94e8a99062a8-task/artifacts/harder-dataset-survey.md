## 2. 适配性筛选分析 (Oracle = 真值查表 + 主动学习闭环)

我们的系统要求：**Oracle 必须有大表做真值支撑，且景观里必须有低阶+高阶的高分变体，让多轮闭环主动学习有足够的纵深**。
*   **能直接插入（只需写 Loader）**：avGFP、ProteinGym (高难DMS)。它们的表结构与 GB1 类似，仅序列更长、位点更多，定长特征可以直接套用 one-hot / ESM-2。
*   **需要改造（变长序列）**：AAV (FLIP)。该数据集在 28-29 氨基酸窗口内发生了突变，部分包含插入/缺失 (Indels)。我们的 `Mutation Designer` 若只枚举替换 (substitutions)，可能无法命中 Indel 的真值。**特征端**：one-hot 需要改造为对齐模式，而 ESM-2 天然支持变长序列，因此必须切到纯 ESM-2，或定制对齐。
*   **不可用**：β-lactamase (高阶真值缺失，无法查表闭环)、Meltome (非单基因局部突变景观)。

## 3. Top-1 推荐：AAV 病毒衣壳 (FLIP)
**（Adeno-Associated Virus capsid, Bryant et al. 2021）**

*   **为何更难（对照 GB1）**：GB1 只有 4 个位点（空间 16万，测量了14.9万），是一个被“照亮”的平滑沙盒；AAV 拥有 28 个可变位点（理论空间 $20^{28}$），但仅测了 8.4万个[需核实]，测量极度稀疏。且病毒组装（Viability）的生物学约束极强，上位效应陡峭，无法轻易从低阶向高阶线性外推。
*   **下载源与文件大小**：[FLIP GitHub / AAV 目录](https://github.com/J-SNACKKB/FLIP) [需核实]，核心 CSV 文件大小约 10MB [需核实]。
*   **字段**：`sequence` (或变异区域序列), `viral_viability` (fitness 真值)[需核实]。
*   **可变区/位点**：VP1 衣壳蛋白的 28 个连续氨基酸区域（通常为 561-588 位）[需核实]。
*   **如何切低阶冷启动**：可采用类似 FLIP 的 `mutational` (2-vs-rest) 切分，即**仅把 HD≤2 的变体（约数千个）放入训练池**，其余高阶高分变体全部隐藏在 Oracle 中。Agent 需从 HD≤2 推理并组合，去命中高阶的存活序列。
*   **预计四策略分化**：
    *   **Random**：在 $20^{28}$ 空间里乱撞，绝大概率抽中完全致死（viability=0）的变体，收益为0。
    *   **Greedy (预测器贪心)**：由于低阶训练数据过于稀疏且上位效应强，预测器（尤其是 Ridge / XGBoost）将出现强烈的幻觉，把某些实际上有冲突的突变生硬组合，导致“开发过度”而中途卡死。
    *   **Agent (无知识)**：在假设生成和 Designer 环节，Agent 能够收敛候选库大小，避免贪心策略下产生过多离谱的高阶长程组合，从而稳定步伐。
    *   **Knowledge Agent**：借助氨基酸理化性质、BLOSUM 保守性约束、或空间拥挤度先验，能排雷掉那些“必定破坏病毒衣壳折叠”的激进替换，从而在极度稀疏的测试集中打出显著的有效命中率差异。
*   **接入改造量与特征建议**：
    *   **改造量**：中等。需要更新 DataLoader；Agent 的 Hypothesis Generator 输出位点范围需放宽到 28。
    *   **建议特征**：**强烈建议使用 ESM-2 (1280维)**。AAV 变体部分包含 Indels，传统的 One-hot 会面临长度不对齐的问题；而 ESM-2 对于变长序列天然兼容，且能带来强大的蛋白质语言表征能力，对抗严重的外部外推(HD外推)。

## 4. 备选推荐：avGFP 绿色荧光蛋白 (Sarkisyan 2016)

*   **为何更难（对照 GB1）**：全长 238 个位点的全域突变。上位效验证了著名的“阈值效应”——累积几个无害突变后，折叠稳定性一旦跌破阈值，荧光会突然消失。这意味着简单的线性累加（Greedy 强项）在此会经常掉入“深渊”。
*   **下载源**：可经 ProteinGym 获取 (`avGFP_Sarkisyan_2016.csv`)，约数 MB [需核实]。
*   **字段**：`mutated_sequence`, `fitness` (log荧光强度) [需核实]。
*   **可变区/位点**：全长 238 氨基酸，全局散布。
*   **如何切低阶冷启动**：抽取数据集中 HD≤2 或 HD≤3 的部分作为冷启动训练集，让 Agent 提拔高阶组合。
*   **预计分化**：Greedy 容易因为不理解折叠稳定性阈值，组合过多的微小正向突变导致蛋白彻底失活。Agent 结合“单次突变数上限”或“保守替换”的知识，能更稳健地攀升。
*   **特征建议**：序列较长，推荐 ESM-2 以捕捉长程上位效应。

## 5. 多数据集项目结构建议

为了让流程轻松在 GB1、AAV、avGFP 间切换，建议在 `data/` 下抽象一层数据集 Registry 与各自的文件夹结构：

```text
data/
├── base_loader.py        # 抽象基类 DatasetLoader (定义 load_pool, get_oracle)
├── gb1/
│   ├── loader.py         # 继承基类，负责处理 V39, D40, G41, V54 逻辑
│   └── four_mutations_full_data.csv
├── aav/
│   ├── loader.py         # 负责处理 28 位点窗口、Indel 对齐、过滤逻辑
│   └── aav_flip.csv
└── avgfp/
    ├── loader.py         # 负责 238 位点全长序列处理
    └── avGFP_Sarkisyan_2016.csv
```

**运行侧改造 (如 `evolution/campaign.py`)**：
*   引入 `--dataset` 参数：`python -m evolution.campaign --dataset aav --cold-start low_hd`。
*   根据参数动态实例化相应的 Loader，并将该 Dataset 的 `wild_type` 序列、`valid_sites` 列表动态注入给 Agent (替代此前硬编码的 GB1 规则)。
