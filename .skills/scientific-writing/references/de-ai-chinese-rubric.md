# 中文学术报告 De-AI 去油与严谨化表达对照表

在科学智能体（AI4S）研究报告中，必须彻底杜绝口语化、口号化与 AI 幻觉修辞。以下为必须遵守的替换规范：

| 范畴 | 严禁出现的口语化/AI 味表达（❌） | 规范学术表达（✅） | 科学严谨性理由 |
|---|---|---|---|
| **标题与定位** | “笔试试卷交付报告（进阶版）” | “面向蛋白质定向进化的受控自演进科学智能体研究报告” | 消除应试口吻，确立独立研究白皮书定位 |
| **情绪化夸大** | “彻底粉碎 7.53 瓶颈”、“断层式的样本效率” | “显著突破 7.53 适应度上限”、“展现出更优的样本利用效率” | 学术报告严禁使用夸张口号与情绪渲染 |
| **口号式断言** | “彻底杜绝无约束套壳调用”、“100% 毫无保留地集中” | “从机制上约束了大模型的调用边界”、“将采样预算完全分配于模型高置信度区域” | 科学陈述必须体现边界感与客观量化 |
| **网文/通俗比喻** | “自由探索踩坑”、“机理尸检” | “无约束主动探索诱发非功能变体富集”、“失效机理反事实归因（Failure Attribution）” | 移除口语化与文学化比喻，使用标准工程与统计术语 |
| **射击/格斗隐喻** | “一击贯穿全局最高峰！”、“一击命中全局最优” | “在首轮测试即收敛至已知全局最优点（8.416）” | 实验结果是客观测量值，非动作描写 |
| **战争隐喻** | “弹药集中度”、“稀释了强攻第一峰的弹药” | “实验采样预算的集中利用”、“探索分支分流了优势序列的采样配额” | 统一量化为“采样预算（Sampling Budget）”与“分配策略” |
| **过度拟人** | “聪明的 LLM Agent 止步于 7.829” | “具备多样性探索机制的 LLM Agent 收敛于次优极值 7.829” | 算法行为是概率采样与策略约束的结果，非拟人智力 |
| **自造隐喻** | 孤立提及“归纳窒息（Inductive Asphyxiation）” | “低阶归纳偏置表达力瓶颈（Expressivity Bottleneck under Inductive Bias）” | 在保留深刻思想的同时，用精确的机器学习理论术语定名 |
