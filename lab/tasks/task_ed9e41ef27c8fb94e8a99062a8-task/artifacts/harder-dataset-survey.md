## 2. 适配性筛选分析 (Oracle = 真值查表 + 主动学习闭环)

我们的系统要求：**Oracle 必须有大表做真值支撑，且景观里必须有低阶+高阶的高分变体，让多轮闭环主动学习有足够的纵深**。
*   **原写「能直接插入（只需写 Loader）」已降格为待验证建议（2026-09-14，应第四轮评审要求）**:涉及 avGFP 与 ProteinGym (高难DMS)。**降格理由**:两者的数据文件均**尚未落地**(avGFP 需 `data/avgfp/avgfp.csv`,当前缺失;ProteinGym 连具体 assay 都未选定),因此「表结构与 GB1 类似、定长特征可直接套用」是**基于未核实格式假设的推断,不是已验证结论**。**已知的反例**:avGFP 的 loader 硬要求 CSV 内含一条显式 WT 行,而 `[需核实]`ProteinGym 的 DMS csv(**外部格式判断,本任务未核验**) 通常不带该行,缺失时直接抛 `ValueError: avGFP CSV must contain an explicit WT row`——即「只需写 Loader」这一判断对 avGFP 已被证伪,尚需数据侧改造。
*   **无需改造（2026-09-14 更正）**：AAV (FLIP) 的 loader 已在 `evolution/datasets.py:61-86` 就位，且其口径**按长度与字母表过滤,顺带排除了 indel 与终止密码子,但 `category` 未被过滤——`designed` 类别仍在池内(30,932/38,265)**，只保留与野生型 `AAV_WT`（28-aa，VP1 窗口 561-588）等长的替换子集，实测 **38,265** 条。因此 one-hot 直接可用，本文档原先「部分含 Indels、必须切到纯 ESM-2 或定制对齐」的判断**方向说反了**，不成立。
*   **原写「不可用:β-lactamase(高阶真值缺失,无法查表闭环)、Meltome(非单基因局部突变景观)」已删(2026-09-14,应第七轮评审)**——「不可用」是选型结论,而`task_plan.md:16` 与 `:79` 规定其只做未核实的初步排序、不承担选型结论;且两条括注理由本仓均无实测、外部亦未核验。**可留的只有**:这两个候选的全部判据在本任务内未核实,不得据本文档排除或采纳。
