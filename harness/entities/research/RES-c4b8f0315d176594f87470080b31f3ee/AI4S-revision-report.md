## 一、认知升华：蛋白质语言模型（ESM-2）的向量化本质

在本次技术研讨中，泽宇提出了一个极为关键、切中计算生物学最底层逻辑的洞见：

> **“ESM 相当于把蛋白质的字母变成向量。字母本身只是人为了方便定义的符号，不蕴含物理规律；但向量之间的距离和正交性，蕴含了空间结构、理化性质和进化规律。我们先用初始数据过一遍 ESM 拿到特征向量，再去训练回归小模型，而不是直接拿字母训练。”**

### 1.1 为什么这一认知是本题的“胜负手”？

在自然语言处理（NLP）中，未经嵌入的单词（Word）只是孤立的 ID，只有经过预训练模型（如 BERT）投影到数百维的高维向量空间后，“词义（Semantics）”才得以呈现（例如经典公式：$\\vec{King} - \\vec{Man} + \\vec{Woman} \\approx \\vec{Queen}$）。

蛋白质完全同构：
1. **氨基酸单字母无信息增益**：如果对 56 个氨基酸直接做 One-Hot 编码，计算机只知道“第 39 位不是 V 就是 I”，它完全不知道 V 和 I 都是疏水链，更不知道如果把 V 换成超大体积的 W 会挤爆三维疏水核心。
2. **ESM 嵌入沉淀了大自然数十亿年的物理规律**：Meta 的 ESM-2 在数十亿条天然蛋白质上预训练，其输出的 **1280 维特征向量（Embedding）**，已经隐式编码了：
   * 氨基酸的立体空间体积（Van der Waals 体积）；
   * 静电荷分布与氢键供受体；
   * 进化保守性（该位点在大自然演化中是否被允许突变）。
3. **小模型的定位是“高维物理空间的轻量打分器”**：
   我们训练的 Random Forest / Ridge / XGBoost 小模型，根本不是从零学习生物学，而是**在 ESM-2 已经提炼好的高质量高维物理表征上，学习一条从表征到 IgG 抗体抓力（Fitness）的超平面**！这就是为什么小模型只需要 0.5 秒训练，预测相关系数（Spearman）就能高达 0.55～0.75 的根本原因。

## 二、原《完整作战文档》的四大硬伤与修正清单

对比原团队起草的 `2026-09-10-AI4S笔试完整作战文档.html`，以下 4 点必须全面推翻重构：

### 🚨 修正 1：彻底废除“静态嵌入死表格”，升级为“M3 Max 128G 本地动态实时 ESM-2 提取”

* **原文档的缺陷（第 140 行、300 行、570 行）**：
  * 原文档假定算力受限，提出：*“我们要用 FLIP 官方预提取好的嵌入文件直接下载……零模型下载、零 GPU……风险：嵌入与本地变体对不上，只能用 FLIP 原生变体集，不自造变体做预测输入”*。
  * **致命弱点**：如果只用死表格，系统就变成了“只能在别人做过的题库里挑题”，一旦 Agent 提出一个表格里没有的全新变体序列，整个流水线当场宕机！这完全违背了定向进化“探索未知候选”的初衷。
* **修正方案（降维打击）**：
  * 泽宇的主力设备为 **Apple Silicon M3 Max + 128GB 统一内存**。
  * GB1 仅有 56 个氨基酸，在 M3 Max 的 Metal 硬件加速（`device="mps"`）下，运行 `esm2_t33_650M_UR50D` 提取一条序列特征仅需 **0.03 秒**，内存占用不到 3GB。
  * **收益**：Agent 可以自由、动态生成任何合法的突变组合，本地即时提取特征并打分，原文档中的“变体对不上”风险彻底清零！

---

### 🚨 修正 2：LLM 决策大脑定调——全面拥抱商业 API，摒弃本地量化模型

* **原文档的缺陷（第 74-80 行、第 521 行）**：
  * 原文档耗费大量篇幅讨论在本地安装 `pydantic-ai-slim[zai]`、跑 GLM-5 甚至微调 pi SDK，技术债务过重，且本地小模型极易发生 JSON 格式漂移。
* **修正方案**：
  * 泽宇拥有充足且稳定的商业 LLM API 资源。
  * 科学 Agent（Hypothesis Generator & Critic）直接配置为标准 API 调用（如 Claude 3.5 Sonnet / GPT-4o / DeepSeek-V3）。
  * 商业大模型的严格 JSON Schema 遵循率接近 100%，不仅零配置负担，而且推理假说的科学论证深度显著优于本地小模型。

---

### 🚨 修正 3：确立“主动学习（Active Learning）双向飞轮”核心战报叙事

* **原文档的缺陷**：
  * 把任务 2（训模型）和任务 5（虚拟实验）割裂成两个单独的机械步骤，缺乏科研系统深度。
* **修正方案（提升答辩立意）**：
  * 正式将泽宇总结的工作流定名为 **“基于主动学习的虚拟蛋白质定向进化双向飞轮”**：
    1. **冷启动阶段**：利用 5,000 条初始历史数据，提取 ESM 向量，训练初始回归器（配发“数字测力计”）；
    2. **假设与初筛**：Agent 像资深科学家一样阅读历史账本，提出 50 个突变假说；利用本地数字测力计 0.01 秒初筛出 Top-10 候选（Top-K 降维提效）；
    3. **虚拟实验化验**：将 10 个候选送入 5 万条真值库（Wu 2016 真实实验表），获取真值反馈（模拟湿实验）；
    4. **模型进化与知识反哺**：将这 10 个新测定的高价值数据回填至训练集（5,000 → 5,010 条），微调小模型，实现测力计的逐轮进化。
  * **立意高度**：向面试官证明，这套系统不仅输出了高活性蛋白，而且在研发全生命周期中为药企**沉淀出了一个越来越准的专属数字孪生预测资产**！

---

### 🚨 修正 4：前端交互展示——收敛为极简实用 Streamlit 看板

* **原文档的缺陷**：
  * 提到了 Chainlit 与 Streamlit 之间的摇摆，以及复杂的事件流渲染。
* **修正方案**：
  * 用纯 Python 编写单个文件的 Streamlit 控制台（`app/demo.py`），提供三个直观模块：
    1. **四策略进化大比武看板**：折线图直观对比 4 条策略的 Fitness 飙升曲线；
    2. **5 人 Agent 思考与挑刺回放**：展示思维链（Chain of Thought）与被规则拦截的积木打架案例；
    3. **任意序列实时试玩器**：面试官随意输入 4 个突变位点，系统现场 0.05 秒完成 ESM 特征提取 + 模型预测，返回预测抓力与化学理由。
