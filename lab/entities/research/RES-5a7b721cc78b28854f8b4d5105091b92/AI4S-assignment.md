题目：面向蛋白质定向进化的科学智能体
一、项目背景
蛋白质定向进化是酶工程、抗体优化和合成生物学中的重要方法。传统定向进化通常依赖科学家根据已有实验结果、蛋白质序列特征和生物化学知识，设计突变库、筛选高活性变体，并迭代优化。然而，蛋白质序列空间巨大，突变组合复杂，不同位点之间还可能存在上位性效应，导致人工设计和随机筛选效率有限。
近年来，蛋白质语言模型、适应度预测模型和大语言模型 Agent 为定向进化提供了新的可能。蛋白质语言模型可以理解序列规律，机器学习模型可以从历史突变数据中学习 fitness landscape，而 LLM Agent 可以模拟科学家的研究流程：阅读背景知识、分析实验数据、提出突变假设、设计候选序列、评估结果并迭代优化。
本项目旨在考察候选者在 AI for Protein、蛋白质数据处理、适应度预测、LLM Agent 设计、结果评估与科研报告撰写方面的综合能力。候选者将在一周内完成一个小规模“虚拟蛋白质定向进化智能体”，利用已有突变数据训练适应度预测模型，并设计一个 LLM Agent 来提出下一轮突变方案。
二、项目任务
候选者需完成以下任务：
	•	数据选择与处理
a. 使用公开蛋白质定向进化或突变效应数据集，例如 ProteinGym、FLIP、GFP、GB1、AAV、β-lactamase 等。
b. 选择一个具体蛋白质任务，例如提高荧光强度、结合能力、稳定性或酶活性。
c. 整理野生型序列、突变序列、突变位点和对应 fitness 分数。
	•	将数据划分为训练集、验证集和测试集，模拟“已完成实验”和“未知候选突变”的场景。
	•	适应度预测模型，建立一个 baseline 模型，用于预测突变蛋白的 fitness。评估模型预测效果，例如 Spearman 相关系数、Pearson 相关系数、MSE、Top-k 命中率等。分析模型能否识别高 fitness 变体。

	•	科学智能体设计
a. 设计一个 LLM Agent，用于模拟科学家的定向进化思维流程。
b. Agent 至少包含以下功能：
i. 读取当前实验数据和 top variants；
ii. 总结哪些突变位点可能有益；
iii. 提出下一轮候选突变序列；
iv. 调用适应度预测模型对候选序列打分；
v. 根据预测结果选择 Top-k 推荐突变；
vi. 给出推荐理由。
c. Agent 可以采用简单模块化设计，例如：
i. Data Analyst：分析历史突变数据；
ii. Hypothesis Generator：提出突变假设；
iii. Mutation Designer：生成候选序列；
iv. Fitness Evaluator：调用预测模型评分；
v. Scientific Critic：检查突变是否合理，并解释结果。
	•	Agent 不要求复杂框架，可使用 prompt + Python 函数调用 + 简单规则实现。

	•	知识增强设计
a. 构建一个小型“定向进化知识库”或“突变规则库”，帮助 Agent 做决策。
b. 知识可包括：
i. 氨基酸理化性质，如疏水性、电荷、大小、极性；
ii. 保守替换与激进替换；
iii. 突变数量限制；
iv. 避免引入终止密码子或异常氨基酸；
v. 避免一次引入过多突变；
vi. 优先组合历史上表现较好的单点突变。
c. 可进一步构建简单知识图谱，例如：
i. Amino Acid — has_property — Hydrophobic；
ii. Mutation — occurs_at — Position；
iii. Mutation — improves — Fitness；
iv. Variant — contains — Mutation。
	•	比较有无知识增强时，Agent 推荐序列的差异。

	•	虚拟定向进化实验
a. 以已有训练数据作为“第一轮实验结果”。
b. Agent 基于当前数据提出下一轮候选突变。
c. 使用测试集中真实 fitness 或训练好的预测模型作为“虚拟实验评估器”。
d. 至少模拟 2—3 轮迭代优化。
	•	观察推荐序列的 fitness 是否逐轮提升。

	•	结果分析与展示
a. 展示每一轮 Agent 推荐的 Top-k 蛋白突变。
b. 分析推荐突变是否集中在关键位点。
c. 比较以下方法：
i. 随机突变；
ii. 适应度模型直接推荐；
iii. LLM Agent 推荐；
iv. 知识增强 LLM Agent 推荐。
d. 分析 Agent 的成功案例和失败案例。
	•	讨论 LLM Agent 是否真正学到了“科学家思维”，还是只是调用预测模型。

三、详细要求
	•	实验报告
a. PDF 格式，3—5 页，包含以下内容：
i. 背景与问题定义；
ii. 数据集介绍；
iii. 适应度预测模型；
iv. LLM Agent 设计；
v. 知识增强方法；
vi. 虚拟定向进化实验结果；
vii. 失败案例分析；
viii. 改进建议与未来拓展。
	•	代码
a. 提交 GitHub 链接。
b. 包含数据处理、模型训练、Agent 推理、候选突变生成和评估代码。
c. README 中说明运行环境、数据来源、运行命令和主要结果。
	•	代码应能在小规模数据集上复现实验流程。
	•	结果展示
a. 展示野生型序列和若干突变序列。
b. 展示每轮推荐的 Top-k 突变方案。
c. 用表格或曲线展示 fitness 是否提升。
d. 展示 Agent 的推理过程，例如：
i. 发现哪些位点可能重要；
ii. 为什么选择某些氨基酸替换；
iii. 为什么组合某些突变；
iv. 哪些推荐失败，原因可能是什么。
	•	可使用资源
a. 公开数据集：ProteinGym、FLIP、GFP、GB1、AAV、β-lactamase 等。
b. 开源蛋白质大模型：ESM、ProtT5、SaProt 等。
c. 机器学习模型：Random Forest、XGBoost、MLP、Gaussian Process 等。
d. Agent 工具：LangChain、LlamaIndex、OpenAI API，或自行实现的 prompt + Python 函数调用。
e. Python 工具：pandas、scikit-learn、PyTorch、Biopython、matplotlib 等。⚠️ 注意：使用外部数据、模型、代码或 ChatGPT 辅助工具时，需在报告中注明来源和使用方式。
四、考核重点
本项目不要求候选者完成真实湿实验，也不要求训练大型蛋白质模型，重点考察以下能力：
	•	是否理解蛋白质定向进化的基本科学流程；
	•	是否能处理真实蛋白突变与 fitness 数据；
	•	是否能训练一个合理的适应度预测模型；
	•	是否能把 LLM Agent 设计成“假设生成—突变设计—模型评估—反馈迭代”的科研流程；
	•	是否能合理引入氨基酸性质、突变规则或知识图谱；
	•	是否能通过实验比较证明 Agent 的作用；
	•	是否能分析模型失败原因，而不是只展示成功样例。
五、加分项
	•	使用主动学习、强化学习策略选择下一轮突变；
	•	使用不确定性估计，例如 Gaussian Process 或模型集成；
	•	比较单点突变、双点突变和多点突变的优化效果；
	•	引入蛋白质结构信息或保守位点分析；
	•	使用知识图谱表示“位点—突变—性质—fitness”的关系；
	•	实现一个简单可交互 demo，输入野生型序列后自动推荐突变方案；
	•	讨论该系统如何连接真实自动化实验平台。
