# 真实研究目标与前沿规划（v0.3 校订）

目标驱动停止应指定指标、单位、阈值、对照、复测置信度与成本；AAV包装分数不能换算为亲和力或“五倍活性”。冷启动已满足单一目标时应先判定是否还需搜索。连续两轮无改善和残差仅是诊断信号，不能直接等同于信息期望价值。

多目标向量包含活性、稳定性、免疫相关表型及表达量，以非支配集合报告权衡。6—7位点为候选设计范围，不存在低阶突变必然无法多目标改善的结论。当前数据没有多表型测量，不能称已实现临床级优化。

知识审计：378个位点对在冷启动均被覆盖；门内11130种具体残基对中7937种未见（71.31%）；9533个门内候选中6852个含至少一个未见对（71.88%）。分母必须明确。覆盖与理化分层是可验证启发式，结构软权重是尚未执行的增量方案。

结构需固定来源、版本、链、组装体与残基映射；未知距离不补造。w=1+exp[-(d/8Å)^2]为预注册候选函数，非测得能量。缺结构时w=1。结构接触不等于正向功能上位。

五条流水线：数值内环、外环诊断、覆盖/结构知识、多目标求解、真实自动化实验。五机则为执行器、验证器、控制器、记忆器、改进器，两种分解不可混同。当前外环是人机协同研发，独立的自主改进收益未证实。哈希账本支持可追溯性，不能自动证明因果关系或免疫评价作弊。

未来验证：冻结未用于设计的任务；统一门禁和编号；比较等预算覆盖、理化、结构及匹配随机对照；报告peak与strong两种终点和完整资源成本。SiLA 2是待选设备接口，并未完成真实移液/测序闭环。制图数据见报告evidence/figures_data/。
