物理与生物化学底层

许多计算机背景的研究者容易把蛋白质设计简单当成一个连续数值优化问题。然而，生物大分子是一个典型的高维离散、非凸、崎岖且充满断层的“自旋玻璃（Spin Glass）”能量地貌。

1️⃣ 经典加性假设的致命破产

传统的机器学习（如 Ridge 线性回归、简单神经网络）默认采用加性假设（Additive Assumption）：认为每个残基突变的效果是独立累加的：

f_{ ext{additive}}(oldsymbol{x}) = f_0 + \sum_{i=1}^L h_i(x_i)

为什么会死？如果突变位点之间在三维空间中互相接触，它们会形成盐桥、氢键或空间位阻。这就导致：“1 + 1 不等于 2，甚至 1 + 1 = 0（致死）或 1 + 1 = 10（暴击）”。这种残基之间的非线性相互作用，在遗传学与物理学中被称为上位性（Epistasis）。

2️⃣ 统计物理广义 Potts Hamiltonian

真实的蛋白质能量曲面遵循统计力学中的广义 Potts 相互作用模型（白皮书一理论推导）：

H(oldsymbol{x}) = \sum_{i=1}^L h_i(x_i) + \sum_{i < j} J_{ij}(x_i, x_j) + \sum_{i < j < k} K_{ijk}(x_i, x_j, x_k) + \dots

其中 $J_{ij}$ 表示二阶成对相互作用势能，$K_{ijk}$ 表示三阶残基微环境协同。当成对与高阶项符号相反时，能量地貌就会出现阻挫（Frustration）——形成极其崎岖的自旋玻璃地貌，局部极值星罗棋布。

1. 探索税（Exploration Tax）的形式化定义

在经典机器学习强化学习中，“平衡探索与利用”被奉为圭臬。但在 2025–2026 年的前沿运筹理论中（Harris & Slivkins 2026, 白皮书二），研究者指出了一个深刻的反常识：

\Delta_{ ext{tax}}(T) = \max_{t \le T} f(oldsymbol{x}_t^{ ext{greedy}}) - \max_{t \le T} f(oldsymbol{x}_t^{ ext{agent}})

为什么在有限预算下探索会变成“税负”？
• 在无穷步（$T o \infty$）下，探索必不可少；
• 但在有限步（$T = 288$）下，任何脱离当前后验分布高置信区间的探索动作，都会直接占用高潜力变体的采样配额！
• 尤其是在生物序列中，高突变位点的预测方差 $\sigma(oldsymbol{x})$ 奇大无比，如果你用经典的 UCB（均值 + 方差）去采样，大模型就会狂热地去探索那些突变多、方差大的区域，结果 100% 踩中致死突变（致死率与方差相关系数 $r = +0.47$）！这笔高昂的学费就是探索税。

2. 信息价值函数（VoI, Value of Information）采集算子

为了打破探索税惩罚，我们在白皮书二与四中严格推导了信息论价值采集算子：

lpha_{ ext{VoI}}(oldsymbol{x}) = \mu(oldsymbol{x}) + \lambda_t \cdot rac{1}{2}\ln\left(1 + rac{\sigma^2(oldsymbol{x})}{\sigma_{ ext{noise}}^2} ight) + u_t \cdot \Delta ext{Tr}(\Sigma_{ ext{epi}})

三大项物理意义：
1. $\mu(oldsymbol{x})$：当前代理模型的预测均值（直接贪心利用）；
2. $\lambda_t \cdot I(oldsymbol{x}; f)$：互信息增益（缩减全局认知不确定性）；
3. $ u_t \cdot \Delta ext{Tr}(\Sigma_{ ext{epi}})$：高阶上位参数协方差迹消除量（通过 Sherman-Morrison 公式更新，专门挑选那些能消除成对/三阶参数歧义的关键变体）；
4. 有限时间步退火（Horizon Annealing）：权重随轮次线性衰减 $\lambda_t = \lambda_0 rac{K - t}{K - 1}$，在最后一轮完全退化为 0，实现“前期摸底消歧义，后期果断纯收割”！

假说 D：测量漂移

湿实验读数出现批次方差或系统误差。诊断手段：重测冷启动基准探针，核验信噪比。

❓ Q1：你们的 Agent 到底跟传统的主动学习（Active Learning）或贝叶斯优化（BO）有什么本质区别？

高分应答：传统的 BO 或主动学习本质上是“固定假设空间下的参数拟合器”。它假设底层的先验核函数（如 Matern 核或线性核）是正确的，只是去调整参数。但当遇到复杂的蛋白质高阶上位断层时，加性核函数的表达力彻底破产（真峰被判定为只有 6.30 分，排第 2,776 位）。传统的 BO 在这里只会永远在死山头上打转。而我们的 Agent 拥有外环元演进能力——它能通过因果归因状态机识别出是“模型表达力赤字”，从而在沙箱中重构出成对 Potts 相互作用模型，实现表征空间的跃迁！

❓ Q2：既然在 v0.4 确定性贪心（Greedy）也能跑到 8.416，那你们做 LLM 智能体的意义到底在哪里？

高分应答：这是一个极其敏锐的问题，我们正是通过对这个现象的深入解剖才取得了 v0.7 的重大突破：
1. 在 v0.4 中，当成对上位模型就绪后，确定性贪心确实踩中了 8.416，但这纯粹是特定随机种子与加性利用的偶然巧合；
2. 我们在 v0.7 实施了严格的多随机种子对照实测：在 mean 纯均值贪心模式下，全 3 个独立随机种子在第 2 轮全部困死在 7.829 的局部次高假山头上，后续 4 轮边际收益恒为 0！这证明纯贪心面对符号上位断层时具有致命的死锁脆弱性；
3. 搭载了停滞反思与回溯机制（Backtrack-to-EXPLORE）的智能体（v0.7），在发现停滞后主动后退重定向，在第 4 轮（仅消费 192 预算）精准跳出了引力阱，成功捕获了 8.4162 全局真峰！这在实证上彻底击碎了“智能体不如贪心”的谬论。

❓ Q3：你们的大模型在整个流水线里到底扮演什么角色？是不是“套壳”？

高分应答：我们对大模型的调用边界制定了极度苛刻的防幻觉原则：
• 绝不在底层搞端到端生成：大模型绝不直接输出未经校验的 28aa 序列，所有序列的有效性全部由硬编码的物理门禁（BLOSUM62 与结构能量）把关；
• 大模型仅被限制在两处元认知决策点：①在输入端，根据统计分析报告提出突变热点假说（必须引用规则 ID）；②在决策端，担任 Scientific Critic 进行全局方向校准，并在检测到连续停滞时触发 Backtrack 回溯决策；
• 底层繁重计算完全交还给数学与代码：张量分解、Ridge 回归、Sherman-Morrison 逆协方差更新全部由确定性 Python/NumPy 算子执行。这是最健康的人机协同与系统控制范式。

❓ Q4：你们如何保证实验过程没有“偷看答案（Data Leakage）”？

高分应答：我们的系统在架构级别实现了绝对的隔离与防泄露：
1. 只读 Verifier 物理隔离：真机标签存放在独立的只读环境中，智能体在提出 48 个候选批次之前，完全接触不到任何候选的真实分数；
2. 单向离线回测闭环：在 14 组离线回测中，Oracle 每次只向算法开放当前批次的测定值，严禁提前排序；
3. 不可篡改事件流审计：每一轮所有的输入提示词、LLM 输出、工具调用参数以及测定回执，全部由带有 SHA-256 签名和时间戳的 Append-only JSONL 事件流严格固化，任何人包括开发者都无法在事后修改实验日志。

❓ Q5：如果要把这套系统应用到药企真实的湿实验（自动化工作站）上，你们的架构怎么对接？

高分应答：我们的五机架构天然就是为了物理世界对接而设计的：
• 内环的 Executor（执行器）可以通过标准 SiLA 2 或 RESTful API 对接自动化液体处理工作站（如 Hamilton Microlab STAR 或 Tecan Fluent），将算法生成的 48 个序列直接编译为移液加样脚本（Worklist）；
• 测序仪或荧光酶标仪的读数生成后，由 Verifier（验证器）作为数据守卫，进行标准化清洗与质控校验，直接沉淀进不可篡改的事件账本中；
• 整个闭环在无人值守的情况下持续运转，人类科学家只需在大本营看板（Streamlit / Web Timeline）上实时监控系统自演进的决策血缘。

❓ Q6：探索税（Exploration Tax）在运筹学上是如何证明的？为什么前期需要退火？

高分应答：在有限时间步 $T$ 的马尔可夫决策过程或强盗问题中，累积最优性差距（Regret）受限于剩余步数。在无穷步下，探索带来的参数方差消除（Information Gain）能在未来的无穷时间中被摊销；但在有限步（如 $T=6$ 轮）下，最后一轮探索的信息在未来完全没有任何变现机会！因此，探索的边际收益必然随剩余步数 $K-t$ 严格单调衰减。我们在白皮书二中证明，只有采用随轮次线性衰减的退火采集算子 $\lambda_t = \lambda_0 rac{K-t}{K-1}$，才能在保证消歧义的同时将探索税降至最低。

❓ Q7：因果归因状态机是如何判断“表征赤字”还是“采样病理”的？

高分应答：状态机采用了严格的反事实控制变量诊断法（Counterfactual Diagnosis）：
• 固定当前的训练集样本，分别用线性模型、成对 Potts 模型与高阶张量拟合，如果高阶模型的拟合残差显著低于线性模型且交叉验证显著更优，判定为表征赤字（Hypothesis A）；
• 如果模型预测真峰本就在高分区，但实际采集动作连续多轮聚集在低方差已知样本点上，判定为采样病理（Hypothesis B），从而激活 Backtrack 强制注入正交扰动。

❓ Q8：RSI 递归自演进系统如何彻底防御 Goodhart's Law（指标降标自欺欺人）？

高分应答：在传统代码生成中，如果允许智能体修改代码，它往往会去修改测试文件（如将 `assert score > 8.0` 改成 `assert True`）。在我们的五机架构中，Verifier（验证器）被设计为由系统独立托管的只读硬件级容器。改进器（Improver）仅拥有对策略模型和采样算子的补丁建议权，其生成的所有补丁必须提交给 Verifier 在独立基准测试集上进行回归检验。改进器没有任何权限修改 Verifier 的代码或测试集，这就从拓扑权限上杜绝了任何降标与作弊。
